A Stream Deck plugin that connects to [Destiny Item Manager](https://destinyitemmanager.com/) (DIM), letting you manage your Destiny 2 inventory directly from your Stream Deck.

## Motivation

I play Destiny 2 and use DIM heavily for inventory management. Alt-tabbing to the browser to move gear between characters gets tedious fast, especially during activities. I wanted a way to trigger DIM actions -- loadouts, item pulls, stat checks -- from physical keys on a Stream Deck, without leaving the game.

## Features

- **DIM integration** -- communicates with DIM through its API for item transfers, loadout applications, and more
- **Configurable actions** -- each key can be mapped to a specific DIM operation
- **Property Inspector** -- customize target character, item selection, and display preferences per action
- **Real-time feedback** -- keys update to reflect current state
- **Elgato Marketplace** -- available as an official marketplace plugin for easy installation

## Getting started

Download the plugin from the [Elgato Marketplace](https://marketplace.elgato.com/product/dim-stream-deck-11883ba5-c8db-4e3a-915f-612c5ba1b2e4) or install it manually from the [GitHub releases](https://github.com/dim-stream-deck/com.dim.streamdeck/releases/latest).

Once installed, add any DIM action to your Stream Deck and configure it through the Property Inspector panel.
